# A06 — Stored ACLs are not an authorization layer

> **PENDING SOURCE.** Built only from the owner's one-line summary (2026-10-01). The addendum wins where it differs, including
> this amendment's number.

## What v2 said

Confluence ACLs captured at ingest were treated as an **authorization layer for the app's own outputs** (the Phase −1 brief lists
"treating Confluence ACLs as an authorization layer for our own outputs" as a conceded mistake). The exact v2 wording is
`TODO: expand from source`.

## The conceded flaw

**Stored ACLs are not an authorization layer.**

## What the amendment changes

**Outputs are gated by the viewer's live permissions via Forge, not by ACLs captured at ingest.**

### How the Spike 3 proof of concept honours it

The PoC's resolver re-checks, at read time and **as the viewing user**, that the viewer can read the counterpart page before it
shows a quote from that page; a conflict whose counterpart the viewer cannot read is hidden and only counted. See
[`../../spikes/03-change-time-trigger-poc.md`](../../spikes/03-change-time-trigger-poc.md).
