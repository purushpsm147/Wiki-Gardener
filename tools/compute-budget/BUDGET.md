Function memory is 512 MB by default and up to 1,024 MB documented (the manifest schema's own maximum is 4,096, which contradicts its description). A naive index for 250k pages (386 MB) would use about three quarters of the 512 MB default and leave little headroom; the compact one (46 MB) fits easily. State must live in SQL anyway, because a function does not keep memory between invocations.
